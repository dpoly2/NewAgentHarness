# Ruflo GOAP Planning

## Overview

Goal-Oriented Action Planning (GOAP) breaks a high-level objective into an ordered set of actions, then uses dependency and cost reasoning to choose the best path. Ruflo's `ruflo-goals` plugin exposes this as the `goal-plan` skill and `goal-planner` agent, using A* style planning with preconditions, effects, and adaptive replanning.

## When ArchonHub Uses It

- Inez triggers GOAP planning automatically when a request produces **3 or more agent dispatches**
- The plan is generated by `goap_planner.py`
- A markdown copy is written to `.agents/agentharness/memory/incoming_files/`
- A JSON mirror is written to `.agents/plans/inbox/` so the current autoloader can import it

## Plan Shape

Each plan contains:

- `plan_id`
- `goal`
- `project`
- `steps[]`
  - `step`
  - `action`
  - `agent`
  - `verify`
  - `depends_on`
- `estimated_agents`
- `complexity`
- `created_at`

## Manual Trigger

Create a plan manually with:

`POST /api/goap/plan`

Request body:

```json
{
  "goal": "Set up the XFTC membership portal with Stripe integration",
  "project": "xftc",
  "write_to_inbox": true
}
```

## Notes on Ruflo

- Ruflo documents GOAP as a **plugin/skill/agent** capability (`ruflo-goals`, `goal-plan`, `goal-planner`)
- The documented surface is MCP/CLI-driven, not a standalone HTTP GOAP API
- ArchonHub therefore uses an LLM-based planner locally and keeps an optional HTTP bridge fallback for a localhost MCP adapter
