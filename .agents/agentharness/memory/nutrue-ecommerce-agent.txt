## Unified Order/Material Tracking System — Nutrue Apparel

### **Objectives**
1. **Consolidate Orders:** Pull order data from both Shopify (hoodswag.shop) and Square POS.
2. **Track Materials:** For each order, track required materials (e.g., blank garments, print types), order type (POD, in-house, custom), and deadlines.
3. **Prioritized Fulfillment Queue:** Output a single, prioritized queue for fulfillment and purchasing.

---

## 1. **Data Sources & Integration**

### **Shopify**
- **API:** Shopify Admin API
- **Data Pulled:** Orders, line items, customer info, fulfillment status, product SKUs, variants, order notes, timestamps.

### **Square**
- **API:** Square Orders API
- **Data Pulled:** Orders, items, modifiers, customer info, payment status, timestamps.

### **Integration Needs**
- **API Access:** Secure API keys for both Shopify and Square.
- **Order Mapping:** Standardize order fields (e.g., SKU, product name, quantity, order date, fulfillment status) across both platforms.
- **Automation:** Use middleware (Zapier, Make/Integromat, or custom Node.js/Python script) to fetch and sync orders on a schedule (e.g., every 10 minutes).
